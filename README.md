# 🎥 Видеочат-Рулетка (WebRTC + Socket.IO + TURN) + 3X-UI

Готовый комплект для быстрого развёртывания анонимной видеочат-рулетки с секретной панелью администратора, собственным TURN-сервером (`coturn`) и панелью управления VPN (`3X-UI`) на одном домене.

## 🚀 Быстрая установка на новый сервер (Ubuntu / Debian)

1. Направьте **A-запись** вашего домена на IP-адрес сервера.
2. Подключитесь к серверу по SSH и выполните одну команду:

```bash
REPO="woodolf/chatroulette-3xui.git" && git clone "https://github.com\${REPO}" && cd chatroulette-3xui && bash install.sh
```

3. Введите ваш **домен** и придумайте **пароль для админки** по запросу установщика.

## ✨ Возможности
* **Видео и звук P2P (WebRTC):** прямой обмен потоками + встроенный TURN-сервер (`coturn`) для стабильной связи через мобильный интернет (4G/LTE) и сложные NAT.
* **Автоматический поиск:** мгновенный подбор случайного собеседника и автопереключение при выходе партнёра.
* **Секретная панель администратора:** вызывается поверх чата по комбинации **`Ctrl + Shift + A`** (на ПК) или **5 быстрым нажатиям** на логотип (на телефоне).
  * Просмотр активных видео-пар и онлайн-списка с IP.
  * Прямое подключение к любому пользователю без очереди.
  * Скрытый видеомонитор для просмотра камер.
  * Сброс пары и бан/разбан по IP.
* **Совместимость с 3X-UI:** панель доступна по пути `/haphq/` (порт `2053`), подписки — `/sub`.

## 🔑 Управление после установки
* **Открыть админку:** `Ctrl + Shift + A` на странице сайта.
* **Сменить пароль админки:** отредактируйте `ADMIN_PASS=...` в `/opt/chatroulette/.env` и выполните `pm2 restart chatroulette --update-env`.
